地震に備える v3.3（図解を削除した文章版）

■ 今回の変更
・前回 v3.2 のアプリ画面・「やること一覧」・「防災取組チェック」の構成を維持。
・防災豆知識の図解15件をすべて取り除きました。
・添付の「3.txt」を data.js の元データとして反映。
　「要約」「ポイント」などの日本語本文は原文のまま採用しています。
・使われなくなった図解用コード、図解用CSS、visualメタデータを削除。
・従来どおり、カテゴリー→項目→詳細の2段階プルダウンで説明を確認できます。
・外部リンクはアプリ画面には表示せず、更新時の参照用に data.js の sources に残しています。

■ 原文からの技術的な修正（文章は変更していません）
・3.txt の文字コードを CP932 から UTF-8 に変換。
・「広域避難場所」「指定緊急避難場所」の2行にあった不正な引用符を半角二重引用符へ統一。
・図解用の visual プロパティ15件のみ削除（画面にも画像は表示されません）。

■ GitHubへ反映する方法
1. ZIPファイルを解凍する。
2. GitHubの住民向けリポジトリを開く。
3. ZIP内のファイル8点を、リポジトリのルートへ上書き登録する。
4. Commit changesを押して登録する。
5. 公開URLを開き、必要に応じ「最新版に更新」を押す。
※ 同名ファイルは更新されるので、ZIP自体をアップロードしないでください。

■ ファイル一覧
index.html: 画面
style.css: デザイン
app.js: アプリ動作
data.js: 住民・町会長、家庭の防災取組、豆知識の内容
manifest.json: PWA設定
service-worker.js: オフラインキャッシュ
icon.svg: アイコン
README.txt: 説明書

■ 注意
・地域名・数値・防災知識等は提供された資料の本文を採用しており、正確性の再検証や文章校正は行っていません。
・公開前に救命救助、避難所の開設条件等の記載を、地域の最新情報に照らして確認してください。
・チェック結果は端末とブラウザの中に保存されます（端末間同期はありません）。
・以前の避難所運営アプリのリポジトリとは別に管理してください。
