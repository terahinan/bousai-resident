地震に備える　v3.2（住民向け防災行動ナビ）

■ 今回の変更
・v3.1 の「住民／町会長のやること一覧」「目標→取組→詳細」「分類→項目→詳細」の構成を維持。
・豆知識の図はスマートフォンの縦方向で読む HTML/CSS の図解に変更（画面全体を横に広げない）。
・利用者画面から外部資料へのリンクを撤去。豆知識には説明と図をアプリ内に収録。
・data.js は提供された a.txt の内容を基に作成。文字コードを CP932 から UTF-8 に変換し、
　構文エラーとなる２つの引用符だけを通常の二重引用符へ置き換えています。
　そのほかの内容は原文のままです。

■ 使い方
1. ZIPを解凍する。
2. GitHub の新しいリポジトリの最上位に、ZIP内のファイルを全て配置する。
3. リポジトリの Settings → Pages で main ブランチの /(root) を公開する。
4. 公開URLをスマートフォンのブラウザで開き、表示と操作を確認する。
   公開URLはGitHubユーザー名／リポジトリ名で異なります。

■ ファイルについて
index.html              アプリ画面
style.css               デザイン・スマートフォン画面幅への調整
app.js                  画面の表示・チェックやプルダウンの動作
data.js             a.txtから変換した行動・取組・豆知識データ
manifest.json           ホーム画面登録名など
service-worker.js       オフライン閲覧とファイルのキャッシュ
icon.svg                アプリアイコン
README.txt              この説明書

■ 注意
・チェック結果や選択した立場、発災日時は、その端末・ブラウザ内にのみ保存します。
・他の端末とは連動しません。
・防災情報、避難所、火災・救助手順等は実際の災害状況や公的発表を優先してください。
・a.txtの地名、施設名、説明、数値は提供文をそのまま採用しました。公開前に地域で確認してください。
・更新管理用の参照元はdata.js内の sources に残していますが、利用者画面には表示しません。
・以前のGitHubリポジトリとは別に作成する想定です。
