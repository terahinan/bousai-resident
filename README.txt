地震に備える v3.5（防災豆知識に図解画像を再追加した版）

■ v3.5 の変更点
・防災豆知識末尾の注記を「記載内容は概ね防災士教本【2025年度版】を参考にしております。」に変更。
・作成責任者を「植柳学区自主防災会」に変更。

■ v3.4 での変更点
・前回 v3.3 のアプリ画面・「やること一覧」・「防災取組チェック」の構成を維持。
・防災豆知識 15項目の各詳細画面に、対応する図解画像を1枚ずつ追加。
・画像の表示位置は「リード文の下」「ポイントの上」。
・画像をタップすると、全画面に近い形で拡大表示できるように変更。
・スマートフォンで開きやすいよう、図解画像は軽量な WebP 形式に最適化。
・オフライン利用時にも画像が表示されるよう、service-worker のキャッシュ対象へ追加。

■ 追加した画像ファイル
・images/trivia/ 以下に 15点の図解画像を追加。
・ファイル名は項目順に 01〜15 の連番で管理。

■ GitHubへ反映する方法
1. ZIPファイルを解凍する。
2. GitHubの住民向けリポジトリを開く。
3. ZIP内のファイル・フォルダを、リポジトリのルートへ上書き登録する。
4. Commit changes を押して登録する。
5. 公開URLを開き、必要に応じ「最新版に更新」を押す。
※ 同名ファイルは更新されるので、ZIP自体をアップロードしないでください。

■ ファイル一覧
index.html: 画面
style.css: デザイン
app.js: アプリ動作
data.js: 住民・町会長、家庭の防災取組、豆知識の内容
manifest.json: PWA設定
service-worker.js: オフラインキャッシュ
icon.svg: アイコン
images/trivia/: 防災豆知識の図解画像15点
README.txt: 説明書

■ 注意
・地域名・数値・防災知識等は提供された資料の本文を採用しており、正確性の再検証や文章校正は行っていません。
・公開前に救命救助、避難所の開設条件等の記載を、地域の最新情報に照らして確認してください。
・チェック結果は端末とブラウザの中に保存されます（端末間同期はありません）。
