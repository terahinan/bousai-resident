地震に備える v3.1

住民向け防災行動ナビ。v1をベースに、次の点を改修。

1. やること一覧
- 住民・町会長の行動データはv1の内容を維持。
- 表示形式を、過去の「避難所開設・運営ナビ」の行動項目カード形式（行動名／状態／時間目安／詳細／注意）に変更。

2. 防災取組チェック項目
- 目標1～3を最初のプルダウンとして表示。
- 目標を開くと各チェック項目を表示。
- 各チェック項目をさらに開くと、解説・確認ポイント・参考資料を表示。
- チェック状態は端末のlocalStorageに保存。

3. 防災豆知識
- 分類 → 個別テーマ → 詳細、の2段階プルダウン。
- 図はインラインSVGを中心に再構成。項目ごとに「何を意味する図か」が分かる見出し・ラベル・注記を付け、横長の図はスマートフォンで横スクロールできる形式。
- 公的機関の公開情報（気象庁、地震本部、京都市、消防庁、日本赤十字社、国土交通省、内閣府、NTT東日本）を中心に整理。
- 内容確認日：2026-10-03。

GitHub Pagesへ公開する場合は、このフォルダ内のファイルを新しいリポジトリ直下へ配置してください。

4. v3.1での追加修正
- 豆知識の閉じた状態は項目名＋「詳細を見る」だけにし、階層が分かりやすい表示に変更。
- 豆知識の図を、文字ラベル付きの詳細なSVG図へ刷新。
- やること一覧は過去の避難所開設・運営ナビのカード形式を維持。
